# Fedfe Buffet

เว็บแอปสั่งอาหารสำหรับร้านบุฟเฟ่ต์ จัดทำในรายวิชา Web Development ด้วย PHP, JavaScript, CSS และ MySQL

- [หน้าลูกค้า — โต๊ะ 1](https://fedfebuffet.freedev.app/?table=1)
- [หน้าเข้าสู่ระบบพนักงาน](https://fedfebuffet.freedev.app/login.php)

## ทำอะไรได้บ้าง

- **ลูกค้า** เปิดเมนูตามหมายเลขโต๊ะหลังพนักงานเปิดโต๊ะ เลือกอาหาร ใส่หมายเหตุในตะกร้า ส่งออร์เดอร์ ดูสถานะ เรียกพนักงาน และขอเช็คบิล
- **พนักงาน** เปิดโต๊ะ จัดการคิวออร์เดอร์ แจ้งอาหารหมด และรับชำระเงินเพื่อปิดโต๊ะ
- **ผู้จัดการ** จัดการรายการอาหารและรูปภาพ นำเข้าเมนูจากไฟล์ JSON จัดการบัญชีพนักงาน และดูรายงานยอดขายรายวัน

โปรโมชั่นมา 6 คน ฟรีค่าบุฟเฟ่ต์ 1 คน สูงสุด 1 คนต่อรอบบริการ เช่น มา 12 คน คิดค่าบุฟเฟ่ต์ 11 คน ส่วนอาหารที่คิดเพิ่มชำระตามปกติ

## บัญชีทดลองจากไฟล์ SQL

บัญชีด้านล่างมาจากข้อมูลตัวอย่างใน [database/fedfebuffet.sql](database/fedfebuffet.sql) รหัสผ่านบนเว็บไซต์ขึ้นอยู่กับข้อมูลที่นำเข้าและการตั้งค่าของบัญชี

| สิทธิ์ | ชื่อผู้ใช้ | รหัสผ่านเริ่มต้น |
| --- | --- | --- |
| ผู้จัดการ | `manager` | `FedfeDemo2026!` |
| พนักงาน | `staff` | `FedfeDemo2026!` |

## ทดลองบน XAMPP

1. วางโปรเจกต์ไว้ที่ `C:\xampp\htdocs\fedfebuffet` แล้วเปิด Apache และ MySQL
2. สร้างและเลือกฐานข้อมูลว่างชื่อ `fedfebuffet` ใน phpMyAdmin แล้วนำเข้า [database/fedfebuffet.sql](database/fedfebuffet.sql)
3. [เข้าสู่ระบบพนักงานบนเครื่อง](http://localhost/fedfebuffet/login.php) ด้วยบัญชี `manager` แล้วนำเข้า [database/menu.json](database/menu.json) ที่หน้าจัดการอาหาร
4. เปิดโต๊ะก่อนทดลองสั่งอาหาร

สำหรับ InfinityFree เลือกฐานข้อมูลว่างที่ตั้งค่าไว้ใน `connection.php` แล้วนำเข้า SQL เดียวกัน ไฟล์เริ่มต้นสร้าง 6 ตาราง โต๊ะปิด 9 โต๊ะ และบัญชีทดลอง 2 บัญชี เมนูและประวัติออร์เดอร์เริ่มต้นว่าง

เมนู JSON ใช้ array ของรายการที่มี `id`, `name`, `category`, `description` และ `price` ไฟล์ขนาดไม่เกิน 1 MB และ ID ต้องไม่ซ้ำกับข้อมูลเดิม หากมีรายการผิด ระบบยกเลิกการนำเข้าทั้งไฟล์
